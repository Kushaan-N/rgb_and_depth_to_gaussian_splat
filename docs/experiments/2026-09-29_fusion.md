# Fusing mocap1–3 into one splat (2026-09-29): rejected for these recordings

**Question.** mocap1–3 were recorded in the same lab and share the OptiTrack world frame. Does one
splat trained on all three fill each path's blind spots (the floor holes) without losing quality?

**Setup.** `bash scripts/run_pipeline.sh fused_mocap_well-lit_trot` (new: `fuse.members` configs,
`scripts/fuse_sequences.py`, `sbatch/pipeline_prep_fuse.sbatch`). Each member's COLMAP-refined poses
go to the metric frame via its own Sim3; the union of the LiDAR clouds seeds the init and the
collider. Each member's usual held-out frames (every 8th) are excluded from fused training, and both
the fused splat and the member's own splat are scored on them at the same COLMAP-derived poses
(`scripts/eval_views.py`). 1,223 training frames, 30k iterations, default trainer.

| member | own splat PSNR / LPIPS | fused, ICP-aligned | fused, Sim3 only | floor: own → fused |
|---|---|---|---|---|
| mocap1 | 34.53 / .172 | 24.42 / .313 | 25.27 / .254 | 0.823 → 0.834 |
| mocap2 | 36.27 / .162 | 23.09 / .339 | 25.20 / .262 | 0.833 → 0.845 |
| mocap3 | 33.87 / .178 | 21.14 / .367 | 22.32 / .294 | 0.842 → 0.832 |

**Checks that rule out the pipeline.**
- The scorer reproduces each member's own trainer metrics exactly (34.53 / 36.27 / 33.87).
- One-member fusion (mocap1 alone through the whole fused path: metric frame, text model, held-out
  exclusion) scores 34.80 / .171 vs 34.53 / .172 — the path is lossless.
- Pose consistency, as median epipolar error of SIFT matches under the fused poses: 0.27 px within
  a recording, 0.73 px across recordings with Sim3 only, 2.0–2.5 px after LiDAR ICP. ICP moved
  mocap2/3 by 4–5 cm while making the cloud NN median slightly *worse* (1.50 → 1.54 cm): the frames
  already agree to ~1 cm and ICP fit noise. Fixing that recovered only ~1 dB.
- Colour: matched points differ by ~6–10% across recordings vs ~4.5% within — a dB or two at most.

**Cause: the scene changed between recordings.** Frames from nearly the same pose (<10 cm, <8°) in
different recordings show the movable objects rearranged — brick stacks, whiteboard, wet-floor
signs, cones, a bicycle, chairs, people (`img/2026-09-29_fusion_cross_pairs.jpg`). Only walls, floor,
shelves and benches are shared. Fused training gets contradictory evidence at every moved object.
Floor coverage barely changes (±1 point), because the floor was never the contradictory part and
the per-member floor was already 82–84%.

**Decision.** Don't fuse these recordings; each is its own world (which is also what a sim needs —
one object layout). The fusion stage stays, because it is correct and cheap for recordings of an
unchanged scene, with three safeguards that came out of this run:
- ICP is kept only if it tightens the clouds by ≥10% (`fuse.min_icp_gain`).
- Prep refuses to train if cross-recording epipolar error exceeds `fuse.max_cross_epipolar_px`
  (1.5 px; the ICP run measured 2.5 px and would have been stopped).
- `summary.json → fuse.verdict` flags any member whose held-out PSNR drops more than
  `fuse.max_heldout_drop_db` (1 dB) — here 9.3 / 11.1 / 11.6 dB, `ok: false`. A pre-training
  image-similarity check for moved objects was tried (local NCC at matched poses: 0.285 within vs
  0.253 across) and is too weak to gate on; the post-training comparison is the reliable signal.

**What would still use the other recordings.** Only their static structure: e.g. floor/wall
geometry from the other members' LiDAR for the floor fill and collider, or other members' images
with movable objects masked out. The floor is already 82–84% covered per member, so the expected gain
is small.
